# 金属与黑色多周期动量工作台

面向期货基本面研究员的技术信号辅助工具。日线四因子是主模型，周线与 60 分钟线用于趋势确认，5 分钟线只用于盘中预警。覆盖沪铜、沪铝、沪铅、沪锌、沪镍、碳酸锂、沪锡、黄金、白银，以及螺纹钢、热卷、不锈钢、铁矿石、焦炭、焦煤、硅铁、锰硅八个黑色主力连续；不包含钴和线材。

## 频率与模型

- 日线四因子：5 日收益率超过 ±3%、突破 20 日高低、收盘相对 MA20、日线 RSI14。
- 触发规则：日线至少 3/4 因子同向，再叠加周线和 60 分钟趋势形成综合结论。
- 频率结论：当前5分钟策略在统一成本后未通过收益与稳定性门槛，已停止5分钟定时交易扫描；日线主模型在收盘后刷新。
- 收盘确认：原始接口返回完整留档，指标层剔除未完成 K 线。
- 快速回测：信号后下一交易日开盘入场，最长持有 10 个交易日，包含双边成本与 2 跳滑点。

## 新增研究层

- 价格 × 品种总持仓：按 20 日价格涨跌与 5 日持仓变化分组；优先直接读取“沪铜加权、沪镍加权”等品种加权合约的持仓字段。没有加权序列时，将当前挂牌的全部分月合约持仓量逐日求和；两者都失败才明确标记“主连降级”。
- 主流技术全景：均线、MACD、ADX、ROC、RSI、KDJ、CCI、ATR、布林带、唐奇安通道、量比和 OBV。
- 技术支撑压力：按当前价就近筛选 20 日高低、MA20 和布林带上下轨；突破区间时用 1×ATR 补充，并保留 2×ATR 止损、0.618 动态跟踪与保本触发。
- 波动率控仓：方向信号与仓位大小分离。ATR14/收盘价处于近252日较高分位或相对近20日均值跳升时，目标仓位依次降至 75%/50%/25%；即使技术多头仍可不加仓。
- 上述模块只作交叉验证与研究辅助，日线四因子仍是唯一核心触发层。

## 回测、模拟盘与全市场

- 策略对比：日线四因子、移动均线 10/30/60、斐波那契 0.618 通道、FDT 启发通道共振、5 分钟动量。
- 交易摩擦：每次开仓和每次平仓分别收取万 1.2，且每侧计 1 跳滑点；信号收盘生成、下一根 K 线开盘执行。
- 绩效报告：页面展示交易数、胜率、等权收益、Sharpe、最大回撤和盈利品种数；完整 JSON 为 `dist/performance-report.json`。
- 前向模拟盘：仅跟踪铜、铝、铅、锌、镍、锂、锡、不锈钢、金、银；页面列示策略收益率、单笔浮盈、波动状态和目标仓位，状态保存在 `state/paper_portfolio.json`。
- 持仓变化：页面列示每个策略的当前方向、入场参考价、最新价、浮动收益与最近开平仓/换向记录；完整记录和净值序列可下载 `dist/paper-history.json` 追溯。
- 信号反转：跨真实扫描比较综合信号、日线信号和评分；多空直接反转或评分跃迁 50 分以上标记为重大变化，状态保存在 `state/signal_state.json`。
- 全市场广度：按每个期货品种一条主力连续统计，覆盖上期/能源、大商、郑商、广期和中金所；明细表仅展示贵金属、有色和黑色。
- 七板块配置：贵金属、有色、黑色、能化、农产品、新能源、金融按板块内全部主力连续等权汇总当日涨跌广度和平均涨幅；页面可展开查看每个品种的价格方向与等权贡献，再决定相对做多前 2、做空后 2。

开源规则参考 [CTAAgents/FDT](https://github.com/CTAAgents/FDT) 与 [VeighNa CTA Strategy](https://github.com/vnpy/vnpy_ctastrategy)。本项目仅提取公开、可解释的趋势与通道思想并重新实现，不包含其 Agent 决策或交易连接层。

## 本地使用

```powershell
.\start-dashboard.ps1
```

打开 `http://127.0.0.1:8765`。该窗口保持运行时，全市场涨跌广度每15分钟刷新，核心模型在交易日15:20后刷新一次，“立即扫描”按钮仍可手动运行完整研究流程。

只扫描一次：

```powershell
.\run-once.ps1
```

安装 Windows 定时任务：

```powershell
.\install-scheduled-task.ps1
```

## 数据边界

国内行情来自新浪财经日线及分钟线接口（与 AKShare `futures_zh_minute_sina` / `futures_zh_daily_sina` 同源）。公开源适合研究原型，不建议直接驱动交易。生产使用应替换为 Wind、iFinD、CTP 或交易所授权源，并使用后复权连续合约或固定主力合约处理换月跳空。

`position_changes` 优先使用东方财富品种加权合约的汇总持仓字段；没有加权序列时再加总同品种全部挂牌分月合约，并列示合约数、覆盖率和成分。它仍不等同于资金净流入，两个汇总口径都异常时才降级为主连持仓变化。

本工具仅用于研究，不构成投资建议或自动交易指令。
